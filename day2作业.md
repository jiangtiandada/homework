|                 |                                    |                                                              |                                             |
| :-------------- | :--------------------------------- | :----------------------------------------------------------- | :------------------------------------------ |
| 方法名          | 含义/作用                          | 示例代码                                                     | 说明                                        |
| **Add**         | 在列表末尾添加一个元素             | `list.Add(100);`                                             | `小括号内为添加的数据类型`                  |
| **AddRange**    | 在列表末尾添加另一个集合的所有元素 | `list.AddRange(["DD", "EE"]); // 参数必须 也是一个集合`
`list.AddRange(new List<string>() { "FF", "GG" });` | `小括号里得是一个集合`                      |
| **Insert**      | 在指定索引位置插入一个元素         | `list.Insert(1,"a");`                                        | `注意: 新增数据的下标 范围 0 到 集合.Count` |
| **Remove**      | 移除列表中第一个匹配的特定元素     | `list.Remove("张三");`                                       | `注意: 数据的下标不要超出范围`              |
| **RemoveAt**    | 移除指定索引位置的元素             | `list.RemoveAt(0);`                                          | `注意: 数据的下标不要超出范围`              |
| **RemoveRange** | 从指定索引开始移除指定数量的元素   | `list.RemoveRange(1, 3);`                                    | 从下标开始删除指定个数                      |
| **Clear**       | 移除列表中的所有元素               | `list.Clear();`                                              | `无参数`                                    |
| **Contains**    | 判断列表中是否包含某个元素         | `bool b = list.Contains("李四");`                            | 返回布尔值                                  |
| **IndexOf**     | 查找元素首次出现的索引位置         | `int idx = list.IndexOf("a");`                               | `找不到返回 `-1`                            |
| **LastIndexOf** | 查找元素最后一次出现的索引位置     | `int idx = list.LastIndexOf("a");`                           | `找不到返回 `-1`                            |
| **GetRange**    | 从列表中复制一段元素形成新列表     | `var newList = list.GetRange(0, 2);`                         | `返回一个list集合`                          |
| **Reverse**     | 将整个列表的顺序反转               | `list.Reverse();`                                            | `无参数将所有顺序翻转`                      |

| Dictionary          |                        |                                            |                                    |
| :------------------ | :--------------------- | :----------------------------------------- | :--------------------------------- |
| 操作方式            | 含义/作用              | 示例代码                                   | 说明                               |
| **索引器赋值** `[]` | 新增或修改键值对       | `dict["name"] = "张三";`                   | `键名不存在就是添加，存在就是修改` |
| **索引器取值** `[]` | 通过键获取值           | `string name = dict["name"];`              | 如果访问了不存在的 元素键名 则报错 |
| **Count**           | 获取字典中键值对的个数 | `int cnt = dict.Count;`                    | `获取个数`                         |
| **TryGetValue**     | 获取指定键的值         | `dict.TryGetValue("age", out dynamic val)` | 返回值为布尔类型                   |
| **Remove**          | 移除指定键的键值对     | `dict.Remove("gender");`                   | 删除指定键值对                     |
| **Clear**           | 清空字典中的所有键值对 | `dict.Clear();`                            | 无参数清楚所有键值对               |
